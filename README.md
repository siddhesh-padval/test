# Attendance Sheet (Roll Numbers 1--10)

This repository contains an attendance sheet for students with roll
numbers 1 to 10.

## Files

-   `attendance_sheet_roll_1_to_10.csv` --- the attendance sheet. Open
    it in Excel, LibreOffice Calc, or Google Sheets.

## How to use

1.  Fill in student names if needed.
2.  Enter `Present` or `Absent` in the **Attendance (Present/Absent)**
    column.
3.  Add any relevant note in **Remarks**.
4.  Save the updated CSV and upload/commit it to the repository so
    students can view the latest version.

## Make it visible online with GitHub

1.  Sign in to GitHub and create a new repository.
2.  Upload `README.md` and `attendance_sheet_roll_1_to_10.csv`.
3.  Set the repository to **Public** if you want anyone with the link to
    view it.
4.  Open the repository page. The README will appear on the page, and
    GitHub will display the CSV in a table when students open the CSV
    file.

**Privacy note:** A public repository can be viewed by anyone. Publish
only information that is appropriate to share publicly, and follow your
institution's attendance-data policy. If attendance information should
be limited to your class, use an institution-approved private platform
instead.
